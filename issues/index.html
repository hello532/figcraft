FigCraft known issues

The problems users actually report in the public tracker — what breaks, which ones are fixed, and the workaround for each. Independent summary, not official.

Known issues from the GitHub tracker

These are the problems users actually report on storytold/figcraft. They are not reasons to avoid the project; they are the edges to know before you trust it with a deadline. Issue state checked 2026-10-19; open the link before acting.

Large .fig imports

Importing big Figma files can fail or take a long time. The tracker has an open import umbrella (#321) and a report for large files (#574); opening large .fig files was improved in #315. Keep the original file and try a smaller page or a fresh export.

Missing fonts fall back silently

Text in a font you do not have can render in another font without a warning (#752, closed). Install the craft-fonts repo next to the app; font rescan/load work is tracked in #821.

macOS 27 / M1 launch crash

There is an open crash on launch on macOS 27.0.1 with an uncaught NSException in _NSTouchBarFinderObservation (#781). Try the latest release and report your build; do not assume every Mac is affected.

Blurred Windows UI after restore

Restored Windows windows can render a blurred DX12 UI; the fix is tracked in #779. Resizing or restarting the window is the usual workaround until it lands.

Small UI on 1440p monitors

The interface can feel small on high-DPI 1440p screens (#540). An interface-size preference is in progress (#818); OS scaling still helps today.

Web build file access

The browser build can open local files through File ▸ Open, import and drag-and-drop; the work is tracked in #830. If a picker does not appear, use a current release and check the issue.

Variable collection crashes (fixed)

Creating a local variable collection used to crash the app (#224, #613). Both are closed; update before reproducing an old crash.

CLI path roots

CLI commands are being confined to automation roots (#839). Keep figcraft-cli inputs and outputs inside the directory you launched it from.

Collaboration is a preview

Live sessions have no accounts, teams or cloud yet, and the public server is not end-to-end encrypted. Self-host the server or use local-network sharing for confidential work.

A closed issue is not a guarantee that every build has the fix: check the release date against the issue’s close date. The most useful bug report includes the OS, build, exact steps and a sample file that can be shared.

What's new in FigCraft 0.10.0

Released 2026-10-22. Housekeeping rather than editor changes: HTTPS enforced on curl downloads (#1016), Actions pinned to commit SHAs (#1015), and hand-rolled UTC conversion replaced with chrono (#975). No editor behaviour changed, per the v0.10.0 release notes, so the issue statuses on this page still reflect 0.9.0.

  • Components and variants from the context menu — combine layers as variants, add a variant to a lone component (#903).
  • A document dropped on the canvas opens as a new file, instead of replacing what you have (#916).
  • Saved documents show their filename, so you can see which file you are editing (#935).
  • SVG export keeps Title Case in place across mixed-style text runs (#958).
  • Open subpaths stay open when reversing subpaths, instead of being closed on you.
  • The pages list keeps the current page in view instead of scrolling away (#930).
  • Switching tools dismisses a comment draft, so no stray comment is left behind (#939).

FreeBSD aarch64 is dropped as of v0.9.0 — it could not be built within the 5-hour CI limit. FreeBSD x86_64 and every other platform still ship.

Frequently asked about FigCraft issues

Why does a large .fig file fail to import in FigCraft?

Large .fig imports can fail or take a long time. The tracker has an open umbrella for this (#321) and a specific report for large files (#574); opening large .fig files was improved in #315. Keep the original file and try a smaller page or a fresh export.

Why does FigCraft crash on macOS 27 or Apple Silicon?

There is an open crash on launch on macOS 27.0.1 with an uncaught NSException in NSTouchBarFinderObservation (#781). Try the latest release first and report your build; do not assume every Mac is affected.

Why does FigCraft show the wrong font?

Text in a font you do not have installed renders in another font without a warning (#752, closed). Install the craft-fonts repository next to the app; font rescan and load work is tracked in #821.

Does FigCraft lose data when importing a .fig file?

Yes, silently in three documented cases: grid auto layout loses its tracks and cell anchors (#465), instance-swap overrides fall back to the main component default (#464), and the import info field does not list what was skipped (#467).

Is FigCraft's multiplayer ready for a team?

No. Live sessions are a preview: no accounts, no teams, no cloud, and the public server is not end-to-end encrypted. Self-host the server or use local-network sharing for confidential work.
