Open-source Figma alternatives: two licences, two bets

Both FigCraft and Penpot publish their source. The licence and the hosting model decide whether that source is a tool you use or a platform you build on.

Independent guide·Updated 2026-10-22·Covers FigCraft v0.9.0·7 min read

The two credible open-source answers

FigCraft is a native Rust application under MIT OR Apache-2.0: a dual licence, which means a downstream user may pick either set of terms. Penpot is a web platform under MPL-2.0, the Mozilla Public License, with a hosted service and paid team tiers on top. Both are open source; they are open in different directions, which matters to anyone building on the code.

MPL-2.0 is commonly summarised as file-level copyleft: changes to MPL-covered files must be published under MPL, while larger works that merely combine with them may carry other terms. Read the licence, or ask counsel, before relying on that summary.

Permissive versus file-level copyleft

MIT and Apache-2.0 ask almost nothing. You may use, modify, embed and redistribute the code, including inside a closed product, provided the copyright and licence notice travel with it. For a design tool, that means a company can fork FigCraft, restyle it, ship it internally or bundle it into a commercial product without publishing those changes. The Apache-2.0 half of the dual licence adds an explicit patent grant.

MPL-2.0 is a middle position: not the viral copyleft of the GPL, since a larger work can combine MPL files with proprietary ones under other terms. But any file that is itself MPL-covered, and any modification to it, must stay available under MPL. For Penpot that is a reasonable fit: a company can run and modify it, and if it distributes a modified version it publishes the modified source files.

The practical question is where your investment lands. If you plan to change the editor and keep those changes private, FigCraft's licence is simpler. If you run a workspace internally and never distribute it, the distinction barely bites, because the obligations attach to distribution.

Hosting is where open source meets the invoice

Penpot's open-source code is offset by a commercial service. The Professional tier is $0 for 8 team members, 10GB and 7 days of history; Unlimited is $7 per editor, capped at $175 a month per team; Enterprise is $25 per member; and a Private Server is $50,000 a year. Those are hosted-service prices, not licence prices: the code is open, and the vendor is selling operations, support and isolation.

FigCraft has no mirror-image offer. There is no hosted product, no enterprise plan and no paid support, so self-hosting is not an option that costs extra; running the binary is the whole product. The trade is reversed. You keep all the operational control and you inherit all the operational work, from fonts sitting in a sibling ../craft-fonts directory (#821 is open) to a macOS 27/M1 launch crash (#781) and broken 1440p interface scaling (#540, #818).

For a company comparing total cost, the honest framing is this: Penpot's free tier buys less code freedom and more operational certainty; FigCraft's permissive licence buys maximum freedom and zero operational certainty. Neither is cheaper in every case.

Parity and community, without the numbers game

FigCraft's roughly 49% parity is the project's own estimate of how much of Figma it covers, and it is the only parity number on this page with a source. We did not produce an equivalent figure for Penpot, and no credible public count of either project's users was verified here, so no chart of adoption appears. What can be observed is structure: FigCraft is a young project with a public issue tracker where bugs are numbered and discussed in the open; Penpot is a shipped platform with a commercial organisation selling seats and a private server around it.

That structure predicts where each will hurt. A young project can change direction quickly and can also stall. A funded platform ships steadily and prices accordingly. For a company placing a five-year bet, the licence is the durable part and the roadmap is the volatile part.

Who should pick which

  • Embedding a design engine in a productFigCraft, if the alpha state is acceptable. MIT/Apache-2.0 lets modifications stay private; MPL would require publishing changes to covered files.
  • Running a design workspace for staffPenpot. The free tier is a real workspace, and there is a paid path with support when the team grows.
  • Security review or air-gapped deploymentFigCraft has no telemetry and no account system, which is the shortest possible review. Penpot can be self-hosted, but the deployment is a server you must run.
  • Needing a vendor to escalate toPenpot, via its Enterprise tier or Private Server. FigCraft has no support contract to buy.

Questions this page answers

Straight answers, with the limits stated. Every claim here is checkable against the sources linked above.

Is FigCraft or Penpot more open?

FigCraft uses MIT OR Apache-2.0, which is permissive: modifications can stay private and the code can be embedded in closed products with attribution. Penpot uses MPL-2.0, which requires changes to MPL-covered files to be published when distributed. FigCraft is more permissive; Penpot is still genuinely open source and self-hostable.

Can I self-host Penpot for free?

Penpot is open source and self-hostable, and the vendor also sells a Private Server deployment at $50,000 a year. The vendor prices that offering around operations and isolation rather than the licence. Whether a free self-hosted deployment is supportable for your team is an operational question this page does not test.

What does MPL-2.0 require of my company?

MPL-2.0 is file-level copyleft: if you modify MPL-covered files and distribute the result, those files must be made available under MPL. A larger work that merely combines them may use other terms. Internal use without distribution triggers no publication duty. Read the licence or ask counsel before relying on a summary.

Does FigCraft have a company behind it?

There is no vendor selling seats, support or hosting for FigCraft: the project is open source at github.com/storytold/figcraft, with bugs handled in a public tracker. That means no support contract and no SLA, and it also means no pricing page to renegotiate.

Which has better Figma parity?

Only FigCraft publishes an estimate: roughly 49% by the project own reckoning, and it labels itself early alpha. We did not produce a comparable parity figure for Penpot and will not guess one. Penpot is the more mature product in the narrow sense of shipping paid team tiers; parity with Figma specifically was not measured for this page.
