Free design tools that run in the browser

Five small tools built for the boring parts of interface design: checking contrast, building a colour ramp, shrinking an SVG, picking a canvas size, filling a layout with placeholder copy. Every one runs locally in the page.

Why these five

They are the checks that come up between a design being drawn and a design being handed off. Each one is also a page that a design tool vendor tends to publish — Figma ships its own colour contrast checker, palette generator and lorem ipsum generator — so the floor for a decent design tool site now includes working utilities rather than screenshots of utilities.

Check

Contrast before review

Text/background pairs fail review, not design. Checking a pair takes seconds and the fix suggestion keeps the hue.

Build

Ramps before tokens

A ramp with a held hue gives you 50–950 names you can paste into variables instead of inventing shades per component.

Ship

Weight before deploy

Design-tool SVG exports carry editor namespaces and four decimal places. Removing them is free bytes.

How the tools relate to FigCraft

FigCraft is an open-source design app written in Rust, currently early alpha at roughly 49% parity by the project's own estimate. These tools do not depend on it: they work if you use Figma, Penpot, Sketch or nothing at all. Where a result maps onto FigCraft, the page says how — a ramp becomes local styles and variables, a canvas size opens in the browser studio, a minified SVG lands in the same file you exported it from.

This site is independent. It is not affiliated with Figma, Penpot, Sketch or ArtCraft, and none of these tools uploads your files anywhere.

Questions this page answers

Straight answers, with the limits stated. Every claim here is checkable against the sources linked above.

Do these tools send my colours or SVG files anywhere?

No. The contrast checker, palette generator, minifier, size sheet and text generator are static JavaScript served from this domain. There is no API call after the page loads, and nothing is written to a server.

Can I use the output commercially?

Colour values, SVG markup and placeholder text are not copyrightable in the way code is, and the tools impose no licence on their output. Your own text and artwork remain yours.

Are these the same tools Figma ships?

No. They are independent implementations of the same jobs. Figma publishes a colour contrast checker, a colour palette generator and a lorem ipsum generator; this page publishes its own versions with the same inputs and no account requirement.

Why do the tools put state in the URL?

So a result is linkable. If you find a failing pair, the URL carries the two colours and the text size, which makes a bug report or a design review comment self-contained.

Contrast checker with a fix, not just a verdict

Paste two colours and see the exact WCAG 2.2 ratio, which levels pass, and the closest colour that would pass while keeping the hue and saturation. Everything runs in this page.

 Free tool

Palette generator: one colour in, eleven steps out

Give it a brand colour. It holds the hue, walks lightness in even perceptual steps, and gives you a named ramp you can paste into CSS variables, a Tailwind config or FigCraft local styles.

 Free tool

SVG minifier that leaves your references alone

Design tools export SVG with an XML declaration, editor namespaces, metadata blocks and four decimal places. This strips the overhead and reports exactly what it removed — without touching ids, text content or gradient references.

 Free tool

Screen sizes, in CSS pixels, with the queries attached

A working sheet of logical viewport sizes and breakpoints. Copy a size, copy the media query, or open the canvas studio at that exact size and start drawing.
