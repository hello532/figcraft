What FigCraft is

FigCraft is a clean-room, open-source take on interface design and prototyping: frames, shapes, text and a canvas you can run locally or in the browser. Its source is on GitHub, so you can inspect it, self-host it, or learn from the implementation.

For quick UI sketches

Lay out a screen with frames, rectangles and labels without opening a heavy desktop app.

For learning

The code is open. Read how a design canvas handles selection, dragging and layers.

For self-hosting

Run it yourself when you do not want client files in a third-party workspace.

How the browser demo works

Three actions are enough to judge whether a design tool fits your hands: create, arrange, export.

  1. Create. Choose Frame, Rectangle or Text, then click the canvas. A frame is a screen; a rectangle is a block; text is a label.
  2. Arrange. Switch to Select and drag any shape. The selected shape gets a blue outline and its position is kept in the layer list.
  3. Export. Press Export JSON to copy the layer tree. Use it as a handoff file or a starting point for code generation.

FAQ

Is FigCraft free?

The project is open source; check the repository licence before you use it commercially. This guide and demo are free and need no account.

Do I need to install anything?

No. The demo runs in this page. The full FigCraft project may offer a hosted or local build; see its repository for the current options.

How is it different from Figma?

Figma is a hosted collaborative product. FigCraft is an open-source alternative you can inspect and self-host. For a solo sketch or a self-hosted workflow, that difference matters; for real-time team collaboration, check the project's current feature set.

Can I use the exported JSON in another tool?

The export is a plain layer list (type, x, y, width, height, text, colour). It is intentionally simple so you can transform it with a script.
