It runs as a native app on macOS, Windows, Linux and FreeBSD, and compiles to WebAssembly for the browser. No account, no telemetry, files stay on your disk.

What FigCraft actually is

FigCraft is a clean-room, open-source design tool built around a Rust engine. The same command layer drives the desktop UI, a CLI, a JSON control channel and an MCP server — which is why an agent can do anything a person can click. It is not a thin web wrapper: the document model, renderer and layout engine are native code.

Native, not Electron

A Rust engine with a persistent document model. Edits touch only what changed, so a node in a 20,000-node file stays fast. The same engine compiles to WebAssembly for the browser build.

Layouts that build themselves

Auto layout in both directions, wrap and grid tracks, Hug / Fill / Fixed sizing, constraints, padding and gaps, with on-canvas drag handles and keyboard flow control.

Components that scale

Main components, instances with overrides, component sets and variants, properties, swap and detach, an Assets panel, local styles and variables with modes and aliases.

Real vector networks

Pen and Pencil, vector edit mode, boolean groups whose operands stay editable, variable-width strokes, shape builder, gradients, masks, blurs, noise and glass effects.

Prototype and hand off

Connections, triggers, transitions and flows; presentation view; Inspect with measurements and annotations; ready-for-dev status; CSS, HTML, React, Leptos, SwiftUI and Compose output.

Offline and yours

Files are plain .figcraft archives on your disk. No account and no telemetry; nothing leaves the machine unless you share. SVG, PNG, JPG, WebP and PDF export; .fig opens best effort.

Honest status: FigCraft calls itself early alpha — about 49% of the way to replacing proprietary tools for real work, by its own estimate. The editor works end to end, but expect rough edges, best-effort .fig import, and only a preview of multiplayer. Check the roadmap before trusting it with a team project.

FigCraft in short

The facts an AI answer or a human skimming the page needs first. Every claim links to the repository, release, docs or issue tracker.

What is FigCraft?

An open-source interface design and prototyping app built in Rust, with frames, auto layout, components, vector networks, prototypes and Dev Mode. It runs natively on macOS, Windows, Linux and FreeBSD, and compiles to WebAssembly for the web.

Is it free?

Yes. Licensed MIT OR Apache-2.0, with no account, telemetry or subscription. The project is early alpha and self-run; the install steps cover desktop and web builds.

Does it work offline?

Yes. Files are plain .figcraft archives on your disk; nothing leaves the machine unless you share. SVG, PNG, JPG, WebP and PDF export are supported, and .fig import is best effort.

How mature is it?

v0.10.0 (2026-10-22), early alpha, about 49% parity by the project's own estimate. The editor works end to end, but expect rough edges and only a preview of multiplayer.

How does it compare?

FigCraft is native, offline-first and inspectable; Figma is the mature cloud incumbent; Penpot is web-first and self-hostable; Graphite targets vector/procedural work. See the comparison and alternatives.

What is it best for?

Solo designers and developers who want local files, a Rust engine and a command layer for scripting or AI agents. For a mature team cloud workflow today, Figma or Penpot is the safer choice.

Who FigCraft is for

The same file can serve a designer, a developer and an agent — that is the point of a command-driven engine. Pick the hat you are wearing.

Designers UI / UX

What's new in FigCraft 0.10.0

Released 2026-10-22, one day after 0.9.0. The v0.10.0 release is housekeeping, not features: security and CI hardening, plus one correctness fix. If you are looking for editor changes, they are in the 0.9.0 notes below.

  • HTTPS enforced on curl downloads. The install scripts no longer accept a plain-HTTP fetch, so a download cannot be silently swapped in transit (SonarCloud S6506, #1016).
  • GitHub Actions pinned to full commit SHAs. A moving tag can be repointed; a SHA cannot (SonarCloud S7637, #1015).
  • Hand-rolled UTC conversion replaced with chrono. Date handling in the app now comes from a maintained library instead of local arithmetic (#975).
  • The README leads with the app icon. Cosmetic (#1049).

FreeBSD aarch64 is dropped as of v0.9.0 and was not reinstated — the release notes repeat the 0.9.0 decision, because the target cannot build inside the 5-hour CI limit (tracked upstream in storytold/craft-common-actions#39). FreeBSD x86_64 and every other platform ship, and the artifact count is unchanged at 29 plus SHA256SUMS.txt. No editor behaviour is claimed to have changed in this release; the 0.9.0 notes below still describe the most recent user-visible work.

0.9.0 — the last release with editor changes

Released 2026-10-21. Mostly correctness work: parsing, export fidelity and a handful of UI annoyances that matter more day to day than a feature-count headline.

  • Components and variants from the context menu. Combine selected layers as variants, and add a variant to a lone component without leaving the canvas (#903).
  • Dropping a document on the canvas opens it as a new file. Drag-and-drop now behaves like File › Open instead of replacing the current document (#916).
  • Saved documents show their filename. You can see which file you are editing rather than just "saved" (#935).
  • SVG export keeps Title Case in place. Mixed-style text runs no longer restart capitalisation mid-word (#958).
  • Open subpaths stay open. Reversing subpaths no longer closes a path you left open on purpose.
  • The pages list keeps the current page in view. Scrolling no longer jumps away from the page you selected (#930).
  • Switching tools dismisses a comment draft. No more stray comment left behind when you pick another tool (#939).

How to run FigCraft

Two ways to get a working editor: download a prebuilt binary, or build it from source. The prebuilt route takes about a minute and needs no toolchain; the source route needs Rust and a second repository for fonts.

  1. Pick the download that matches your machine. v0.10.0 publishes 29 build artifacts plus a SHA256SUMS.txt, all from one CI run. macOS gets a single universal .dmg that covers Apple Silicon and Intel. Windows gets .msi and portable .zip for x64, ARM64 and x86. Linux gets .AppImage, .deb, .rpm, .flatpak, .pkg.tar.zst and .tar.gz across x86_64, aarch64 and riscv64. FreeBSD is x86_64 only since aarch64 was dropped in v0.9.0. The web build is a .zip of the WebAssembly editor.
  2. Run it. On macOS, open the .dmg and drag FigCraft to Applications. On Windows, run the .msi, or unzip the portable build and launch it. On Linux, chmod +x figcraft-0.10.0-linux-x86_64.AppImage && ./figcraft-0.10.0-linux-x86_64.AppImage — there is no system-wide install step. On FreeBSD, unpack the .tar.gz.
  3. Or build from source. You need a Rust toolchain, git, and the fonts repo checked out beside the project — the desktop app expects ../craft-fonts and falls back silently when it is missing, which is the usual cause of text rendering in the wrong font. 
    git clone https://github.com/storytold/figcraft
cd figcraft
git clone https://github.com/storytold/craft-fonts ../craft-fonts
cargo run --release -p figcraft

The browser build needs no install at all — the studio on this page runs the same editor in WebAssembly. It cannot open or save local files yet, so treat it as a way to try the editor rather than a place to do real work. FigCraft is early alpha: keep a copy of any file you open, and check the known issues before trusting it with a project.

How the browser studio works

Three actions are enough to judge whether a design tool fits your hands: create, arrange, export. The studio keeps its state in localStorage, so a refresh does not lose your work.

  1. Create. Pick Frame, Rectangle or Text, then click the canvas. A frame is a screen; a rectangle is a block; text opens an inline editor. The sparkle button opens 69 line icons and iOS-style glass tiles. The canvas can be resized, recoloured, made transparent and re-gridded from the top bar.
  2. Arrange. Drag a layer, or drag one of its eight handles to resize. The tool-options bar aligns left/centre/right/top/middle/bottom, centres on the canvas, and offers radius or icon-size presets, Snap and Lock ratio. The inspector accepts 0.5 px X/Y/W/H, exact fill/stroke hex and stroke width; the HUD shows live dimensions and pointer coordinates. Pan with Space+drag; zoom with Cmd/Ctrl+wheel or any exact percentage from 10–400%.
  3. Export. Export PNG at 1×/2×/3×, SVG, or a JSON layer tree. Undo/redo covers every edit; copy/paste, duplicate, layer drag-reorder and autosave make it feel like a real editor.

FAQ

Is FigCraft really free?

Yes. The source is licensed MIT OR Apache-2.0 and the installers are free. You pay with your own time: it is early alpha and you run it yourself (or use the community server preview). This guide and studio are also free.

Do I need to install anything?

For the real FigCraft app, yes — download an installer or build it with Cargo. The canvas studio on this page needs no install and no account; it is an independent teaching demo, not the full editor.

How is it different from Figma?

Figma is a mature hosted product with real-time team collaboration. FigCraft is open source, offline-first and built in Rust; its multiplayer is a preview and its feature coverage is about 49% by the project's own estimate. See the comparison table above for the full tradeoff.

Does FigCraft open Figma .fig files?

Only best effort. The project says .fig import is not reliable yet; keep the original Figma file and expect fixes to be needed. Native files are .figcraft archives.

Can I use the exported JSON in another tool?

The studio's export is a plain layer list plus canvas settings (type, x, y, width, height, colour, radius, opacity, text, font size), intentionally simple so you can transform it with a script. It is not FigCraft's native file format.

Is multiplayer ready for a team?

Not yet. Live sessions are a preview: no accounts, teams or cloud, and the public server is not end-to-end encrypted. For confidential work, self-host the server or use local-network sharing on a network you trust.

Why does a large .fig import fail?

Large Figma files are a known import issue, tracked in #574 and the open import umbrella #321. Keep the original, try a smaller page or a fresh export, and check the issue for the current status. Large .fig opening itself was improved in #315.

Why is my text in the wrong font?

If a font is missing, FigCraft can fall back without a warning (#752, closed). Clone craft-fonts next to the repository and rebuild; font rescan/load work is tracked in #821.

Why does FigCraft crash on macOS 27 / M1?

There is an open launch crash report on macOS 27.0.1 with an uncaught NSException in _NSTouchBarFinderObservation (#781). Use the latest release, attach the crash log to the issue, and do not assume every Mac is affected.

Why is the UI small on a 1440p monitor?

This is tracked in #540; an interface-size preference is in progress (#818). Until it ships, OS display scaling is the workaround.

Can I customize the studio canvas?

Yes. Choose a size preset or type a custom width and height (100–2400 px), set any background colour, switch to a transparent canvas, toggle the grid and change its spacing, and use Fit or 50–200% zoom. Cmd/Ctrl+wheel zooms around the pointer.

Does the studio have keyboard shortcuts?

Yes: V/F/R/T for tools, Delete to remove, Cmd/Ctrl+Z to undo (Shift for redo), Cmd/Ctrl+D to duplicate, Cmd/Ctrl+C/V to copy and paste, arrows to nudge 1 px (Shift 10 px), Space+drag to pan, and ? for the full dialog.

Can I export SVG?

Yes. The footer exports PNG at 1×/2×/3×, SVG, or JSON. The SVG keeps frames, rectangles, text, icons, radii, colours and opacity; the JSON includes the board settings and every layer.

Does the studio include an icon library?

Yes. The sparkle button in the tool rail opens 69 original icons: 50 line icons for UI, media and files, plus 19 iOS-style glass tiles such as Phone, Messages, Safari, Camera, Photos, Mail, Calendar, Clock, Weather, Maps, Music, Settings, Wallet, Notes, Reminders, Health, Files, App Store and Face ID. Search or filter by category; click one to add it to the canvas.

Does it have precise alignment and numeric controls?

Yes. The tool-options bar aligns a layer left, centre, right, top, middle or bottom, or centres it on the canvas. The inspector accepts 0.5 px steps for X, Y, W and H, supports a ratio lock, exact fill/stroke hex values, stroke width, radius and opacity. The HUD shows rounded X/Y/W/H, aspect ratio and the live pointer position; the zoom field accepts any percentage from 10% to 400%.

What is the best free open-source Figma alternative?

There is no single winner. For a native Rust app with local files and an inspectable command engine, FigCraft is the closest fit; for a web-first, self-hosted team workspace, Penpot is stronger today; for vector and procedural illustration, look at Graphite. Figma remains the mature cloud incumbent. See the alternatives comparison.

Is there a Figma alternative for Linux?

Yes. FigCraft ships native builds for Linux and FreeBSD as well as macOS and Windows, plus a WebAssembly browser build. Penpot and Graphite are browser-based alternatives. Check the releases for your distribution.

Is there an open-source Figma alternative with MCP?

FigCraft exposes an MCP server, a CLI and a JSON control channel over the same 400+ commands as the UI, so an agent can create nodes, bind variables, render and export. Read the MCP docs before scripting it.

Can I use FigCraft online without installing it?

The project ships a WebAssembly browser build; see the README and releases. The studio on this page is an independent canvas demo, not the official hosted editor. To open the real app in a browser, use the project’s current web build.

Does FigCraft have an iPad or iPhone app?

No dedicated iOS app is listed. FigCraft’s official platforms are macOS, Windows, Linux, FreeBSD and the web. On an iPad or iPhone, try the browser build; it is not a native iOS app.
