FigCraft vs Penpot: local files or a hosted workspace

Both are open source, and they disagree about the only question that matters: where the document lives. Everything else follows from that.

Independent guide·Updated 2026-10-22·Covers FigCraft v0.9.0·7 min read
Download FigCraftOpen the studio

Same licence family, opposite architecture

Penpot is a web application. You open a browser, sign in to a workspace and edit a project the server holds; if you want the server to be yours, you run one. FigCraft is a native desktop program. You open a .figcraft file from your disk, edit it offline, and there is no account, no server and no telemetry in the loop.

That difference decides most of what follows: collaboration, offline work, what a backup is, and who carries the operational risk. Where a vendor page did not settle a point, the table says so.

Where Penpot is ahead

Collaboration is not a preview in Penpot; it is the product. Seats are measured in editors and viewers, and the free Professional tier includes eight members plus unlimited viewers. For two designers who need the same file this afternoon, that is the whole argument.

Distribution is the second advantage. Nothing is installed, so a contractor on a locked-down laptop and a stakeholder on an iPad reach the same file with a link. Self-hosting is supported, and the vendor sells a Private Server at $50,000 a year for organisations that need it inside their own perimeter. The free tier is capped at 10GB and 7 days of history — enough to trial a migration, not enough to run a year without exports.

Where FigCraft is ahead

  • The file is the documentNo account, no session, no server that can be down or repriced. A .figcraft file on disk can be emailed, versioned in git, or opened on a plane.
  • Licence terms a company can embedMIT OR Apache-2.0 imposes no obligation to publish modifications. MPL-2.0 keeps modified MPL-licensed files under MPL. For an internal tool the difference is academic; for a product built on top, it is not.
  • Automation as a first-class surfaceA CLI, a JSON control channel and an MCP server with more than 400 commands. Penpot's equivalent surface was not verified for this page, so treat the comparison as open rather than settled.
  • Breadth of outputSVG, PNG, JPG, WebP and PDF export, plus handoff to CSS, HTML, React, Leptos, SwiftUI and Compose. Dev handoff is free here; in Figma it is a paid seat.
  • Native binaries where a browser is a poor fitmacOS, Windows, Linux and FreeBSD, plus a WebAssembly build for when a browser is the only option.

Migration, in both directions

Figma files import into FigCraft on a best-effort basis: the document renders, but features FigCraft cannot represent are dropped, and large files can fail outright (#574, #321). Penpot's Figma import path was not verified here. Migrate a small, recent file first and compare it with the original; rebuilding a live design system is usually cheaper than repairing an import.

Between FigCraft and Penpot there is no import path worth relying on, because one stores projects server-side and the other stores documents as files. Treat a switch as a rebuild.

The remaining objections to FigCraft are on the known-issues list: fonts need a sibling ../craft-fonts directory (#821 is open), macOS 27 on M1 crashes on launch (#781), Windows has a DX12 blur problem, 1440p scaling is broken (#540, #818), and FreeBSD aarch64 was dropped in v0.9.0. Multiplayer is a preview and the public server is not end-to-end encrypted, so it does not replace Penpot's permissions model.

What this page does not claim

No user counts, no benchmark and no parity figure for Penpot. FigCraft's roughly 49% parity is the project's own estimate of its coverage of Figma, not a comparison against Penpot, and it should be read that way. Penpot's maturity is asserted only in the narrow sense that it ships paid team tiers; its feature set was not audited for this page.

Questions this page answers

Straight answers, with the limits stated. Every claim here is checkable against the sources linked above.

Is Penpot fully open source?

Penpot is open source under MPL-2.0 and is web-first and self-hostable. The paid tiers are a hosted service and support arrangement rather than a different codebase, as far as the vendor states. FigCraft takes the other route: MIT OR Apache-2.0, a native binary, and no hosted service at all.

Can FigCraft do real-time collaboration like Penpot?

Not at the same level. FigCraft has multiplayer as a preview, with live sessions from the app or a self-hosted server, no accounts and no permissions, and the public server is not end-to-end encrypted. Penpot treats members and viewers as the unit of its pricing, which is a fair signal that collaboration is the product rather than a preview.

Which is cheaper for a small studio?

Penpot Professional is $0 for up to 8 team members with 10GB of storage and 7 days of history, which covers many studios outright. Beyond that, Unlimited is $7 per editor with a $175 monthly cap, so five editors are $35 a month. FigCraft is $0 with no user limit, but you carry hosting, backups and alpha-quality software yourself.

Does FigCraft work offline?

Yes. It is a native application that opens .figcraft files from local disk, requires no account, and sends no telemetry, so an offline machine is a normal way to use it. Whether Penpot offers an offline mode was not verified for this page; its primary model is a browser session against a server.

Can I import a Penpot file into FigCraft?

There is no import path we could verify, and the architectures make one unlikely: Penpot keeps projects server-side while FigCraft works on files. Moving between them should be planned as a rebuild. Figma files are a separate case, where FigCraft offers best-effort .fig import that can lose features silently.
