FigCraft templates: eight starters, one menu

The app ships eight starters, and they all live behind one menu item. This is the map: what each file contains, the size it is drawn at, and where it stops being useful.

What ships in the app

Eight starters, one per job, all opened from File ▸ New from template. The project lists the eight names and does not publish their internal pages or frame sizes, so each page below documents a workable structure you can build against.

390 × 844

Mobile app

Launch to settings in six phone screens, with an Android frame at 412 × 915 for a density check.

 1440 wide

Landing page

Hero, logo strip, features, proof, pricing, FAQ and footer on a 12-column grid.

 1440 × 900

Dashboard

Sidebar, top bar, stat cards, a data table and chart placeholders in an editable shell.

 1440 × 1080

Design system

Foundations sheets, local styles, variables with light and dark modes, component sets.

 1440 × 1024

Wireframe kit

Gray placeholders at desktop, tablet and phone widths, built from five block components.

 1080 × 1080

Social post sizes

Feed, portrait, story and link-preview frames with the platform-covered areas marked.

 1920 × 1080

Presentation slides

Seven 16:9 layouts wired into a prototype flow you can play in presentation view.

 24 × 24

Icon set

A 24 px grid with 1.5 px and 2 px strokes, plus 16 and 20 px derivatives.

How the starters are built

All eight lean on the same three engine features, which is why they survive editing. Nothing is flattened, and nothing depends on a plugin.

Auto layout

Frames that reflow

Both directions, wrap, grid tracks, and Hug, Fill or Fixed sizing. A page section is a vertical stack with padding; a row of cards is grid tracks, so widths stay equal when you add a fourth card.

Variables and styles

Tokens with modes

Local styles carry text and effects; variables carry color and spacing with modes and aliases. Switching the mode on a page restyles it without touching a layer.

Components

Variants, not copies

Buttons, rows and cards are component sets with variants and properties. Edit the main component and every screen in the starter follows.

Output

Where the file goes next

Inspect with measurements and annotations, mark a frame ready for dev, then export CSS, HTML, React, Leptos, SwiftUI or Compose — or SVG, PNG, JPG, WebP and PDF.

Read this before you trust a starter

FigCraft v0.9.0 shipped on 21 October 2026, and the project still calls it an early alpha with about 49% parity by its own estimate. The templates reflect that: they are seeds for a project, not finished brand systems, and a frame that renders today may need a small fix after an update.

The practical consequences are worth knowing before you plan a week around one of these files. Text needs the craft-fonts repository cloned beside the source or it silently falls back to a system face (#821 tracks rescanning; #752 is closed). macOS 27 on M1 has a launch crash (#781), FreeBSD aarch64 builds were dropped in v0.9.0, and .fig import is best effort with large files still failing (#574, #321). Check known issues first, and install the build that matches your platform.

Questions this page answers

Straight answers, with the limits stated. Every claim here is checkable against the sources linked above.

Where are the eight starters in FigCraft?

Under File ▸ New from template. The list is mobile app, landing page, dashboard, design system, wireframe kit, social post sizes, presentation slides and icon set. There is no marketplace and no download step: the starters ship with the app, so they work offline.

Do the templates cost anything?

The starters ship with the application. FigCraft itself is open source under MIT OR Apache-2.0 and asks for no account. This guide is independent and not affiliated with the project, so check the repository licence for the terms that actually bind you.

Can I use a starter for client work?

The repository licence governs redistribution, and it is MIT OR Apache-2.0. Read it rather than this page. What the starter gives you is a structure to replace — you are expected to swap the type, color and components for the client brand.

Which starter should I open first?

Open the one whose artifact you must hand over. For a layout argument use the wireframe kit; for a buildable screen use the dashboard or mobile app; for tokens use the design system.

Why does text in a starter look wrong?

Almost always the font path. FigCraft needs the ../craft-fonts repository cloned beside the source; without it, text silently falls back to a system face and your sizes shift. #752 is closed; #821 tracks rescanning once the fonts are in place.
