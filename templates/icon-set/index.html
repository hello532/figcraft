Icon set template: a 24 px grid, two stroke weights

A 24 × 24 grid with 1.5 px and 2 px strokes, plus 16 and 20 px derivatives. Vector networks and boolean groups, SVG out.

What's in the starter

The project publishes the name of this starter, not its internal pages or frame sizes. What follows is a workable structure for this kind of file — a starting spec to build against — not a transcription of the shipped document. Check it against the build you actually open.

Four pages: the 24 px master grid, a 20 px and a 16 px derivative set, and an index sheet. Every glyph is a component with a weight variant, so the set stays consistent when you add an icon.

  • Master gridA 24 × 24 frame with a 2 px padding ring, leaving a 20 px live area. Key shapes sit on 2 px increments and strokes are centred on the grid.
  • Two weights1.5 px is the default stroke and aligns to the pixel grid at 24 px; 2 px is the heavier variant used for 24 px navigation and toolbar glyphs.
  • Derivatives16 × 16 and 20 × 20 sets drawn from the same geometry, both on the 1.5 px stroke — a 2 px stroke at 16 px closes the counters in small shapes.
  • Compound glyphsIcons built from more than one shape use boolean groups and vector networks, so the outline stays one editable object rather than a stack of overlapping paths.
  • Index sheet1440 × 1080 contact sheet of 14 × 10 cells at 64 px with 24 px gutters, so the whole set is visible at once and a missing icon is obvious.
  • Grid spec sheetThe construction rules drawn on one frame: 24 px box, 2 px padding, 20 px live area, and the two stroke weights side by side.

Open it

  1. File ▸ New from template — choose “Icon set”. The four pages open; the master grid is the one to read first.
  2. Save it next to the product — an icon file outlives most screens. Keep it in the same place as the design system so color and stroke stay aligned.
  3. Add icons on the master page — draw at 24 px, then let the weight variant produce the heavy version instead of drawing both.
  4. Check alignment at 100% — zoom to actual size before approving a glyph; a stroke that looks centred at 800% often is not.
  5. Confirm fonts — labels on the index sheet are text. Without ../craft-fonts they fall back like any other text in the app.

Make it yours

A set stays coherent through three mechanisms, all of which the starter already uses.

Components

One icon, two weights

Each glyph is a component with a weight property. Instances on the index sheet update together, so a curve fix propagates instead of being repeated 40 times.

Vector networks

Cleaner joints

Networks let three paths meet at one point without overlapping ends. That is what keeps a 1.5 px stroke from showing a seam at an intersection.

Variables

Color per mode

Icon color is a variable, so the set follows light and dark modes. Check the pair against the contrast checker before shipping a 16 px version.

Export

SVG, then minify

Export SVG per selection and run it through the SVG minifier. Keep the vector networks as the source; the SVG is a copy.

What it does not give you

There is no sprite-sheet build, no icon-font generator and no library browser. Export gives you SVG, PNG, JPG, WebP or PDF for what you selected, one export at a time — the sprite or the font is your build step, not the starter's.

The starter is a grid and a handful of glyphs, not a complete icon library; you will draw most of your set. The 49% parity figure is the project's own estimate, so expect the vector tools to be less forgiving than a mature editor when you push a tricky boolean. Keep an eye on known issues, and if the app itself looks cramped on a 1440p display that is #540 and #818, not your icon file.

Questions this page answers

Straight answers, with the limits stated. Every claim here is checkable against the sources linked above.

What grid does the icon starter use?

A 24 × 24 frame with a 2 px padding ring, leaving a 20 px live area. Key shapes land on 2 px increments. The 20 px and 16 px sets are drawn from the same geometry rather than scaled, because scaling a stroke changes its weight.

Which stroke weights are included?

1.5 px as the default and 2 px as the heavy variant at 24 px. The 16 and 20 px derivatives use 1.5 px only — a 2 px stroke at 16 px fills in the counters of small glyphs like a play triangle or an asterisk.

Can I export an icon font or sprite sheet?

No. Export writes SVG, PNG, JPG, WebP, PDF or CSS, HTML and code output for a selection or frame, one at a time. Building a sprite or an icon font is a separate step in your own pipeline; run the SVGs through the SVG minifier first.

Are the icons components?

Yes. Each glyph is a component with a weight variant, and the index sheet uses instances. Fix a curve in the main component and every size and weight that references it updates, which is the only reliable way to keep a large set consistent.
