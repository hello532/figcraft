Social post template: four frames, one message

Four export sizes in one file: 1080 × 1080, 1080 × 1350, 1080 × 1920 and 1200 × 630. Draw the message once, then resize the stack for each ratio.

What's in the starter

The project publishes the name of this starter, not its internal pages or frame sizes. What follows is a workable structure for this kind of file — a starting spec to build against — not a transcription of the shipped document. Check it against the build you actually open.

One page holds the four canvases at full size, a lockup sheet and a type sheet. Each canvas is a vertical stack with a fixed margin, so the same copy can be dropped into all four.

  • Square feed post1080 × 1080 with a 96 px margin, a 96/104 headline block, a 48/56 sub-line and a 24 px legal line at the foot.
  • Portrait feed post1080 × 1350, the same stack with more vertical room, so the headline can run three lines without shrinking.
  • Story and reel1080 × 1920 with two guides marking the top 250 px and bottom 340 px that app chrome tends to cover, leaving 1330 px of safe vertical space.
  • Link preview1200 × 630 with a 64 px margin, a 64/72 headline and a left-aligned lockup, since the card is usually shown beside a URL.
  • Lockup sheetA 1080 × 1080 sheet with the logo mark, the wordmark and three lockup variants as components, so every canvas uses an instance.
  • Type sheetThe four sizes used on the canvases — 96, 48, 32 and 24 px — as text styles, so a copy change cannot invent a fifth size.

Canvas spec

Pixel sizes only, no device frames. The story frame is the only one where height is constrained by someone else's interface, which is why it carries guides rather than a layout.

Open it

  1. File ▸ New from template — choose “Social post sizes”. The four canvases open at full pixel size, so expect to scroll.
  2. Save the file — a campaign folder is usually a set of files; name this one after the campaign, not the template.
  3. Replace the lockup first — edit the component on the lockup sheet and all four canvases update at once.
  4. Write the shortest version first — set the copy on the square, then let the portrait and story frames take the extra lines.
  5. Check fonts — display sizes expose a fallback face immediately. If the headline looks like a system font, ../craft-fonts is missing beside the source.

Make it yours

Campaign work is repetition. These four settings remove most of it.

Auto layout

One stack, four ratios

The caption stack is Fill width with Hug height, pinned inside a 96 px margin. Change the headline and the block grows; nothing overlaps the legal line.

Variables

Two card themes

Light and dark card modes are variable modes, so the same post can ship as a light feed card and a dark story without a second set of layers.

Components

Lockup and corner tag

The lockup has three variants for width, and the corner tag is a component with a text property. Instances keep the mark identical across sizes.

Export

PNG, JPG, WebP or PDF

Export per frame. Flat layouts survive PNG and SVG; photographic backgrounds are smaller as JPG or WebP. Check the scale before promising a 2160 px file.

What it does not give you

There is no publishing, no scheduling and no platform API. Export writes an image or a PDF; posting is still a manual upload. Nor does the starter resize one design into four — you duplicate the stack and adjust, which is why the copy is written short first.

The safe-area guides on the story frame are approximations of where app chrome sits, drawn on the canvas rather than enforced by anything. They vary with device and app version, so confirm against the platform's current guidance before a paid placement. Text sizes here are tuned for the bundled faces: without craft-fonts, 96 px display type falls back and lines rewrap. See known issues if the export looks different from the canvas.

Questions this page answers

Straight answers, with the limits stated. Every claim here is checkable against the sources linked above.

What sizes does the social post starter include?

1080 × 1080 for a square feed post, 1080 × 1350 for a 4:5 portrait post, 1080 × 1920 for a story or reel, and 1200 × 630 for a link preview. Each is a separate frame at full pixel size, not a scaled copy.

Are the story safe areas exact?

No — they are guides drawn at 250 px from the top and 340 px from the bottom of a 1080 × 1920 canvas, which is where app chrome usually sits. The real values change with device and app version, so treat them as a working margin and check the platform guidance for a paid placement.

Can FigCraft publish or schedule the post?

No. There is no account, no cloud and no platform integration. Export produces PNG, JPG, WebP, PDF or SVG for the frame you selected, and the upload stays manual.

Can I resize one design into all four frames at once?

There is no batch resize. Duplicate the caption stack into the next frame and let auto layout Fit and Fill do the arithmetic; the four frames share text styles and components, which is what keeps them consistent. Write the shortest copy first so the square does not force a rewrite later.
