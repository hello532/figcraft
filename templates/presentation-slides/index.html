Presentation template: seven 16:9 layouts at 1920 × 1080

Seven layouts at 1920 × 1080, built as frames and connected as a prototype flow, so you can present from the file you designed in.

What's in the starter

The project publishes the name of this starter, not its internal pages or frame sizes. What follows is a workable structure for this kind of file — a starting spec to build against — not a transcription of the shipped document. Check it against the build you actually open.

One page, seven slide frames, plus a compact 1280 × 720 frame for older projectors. Slide furniture — kicker, footer, page number — is a component, so every layout shares it.

  • TitleA 96/104 headline, one line of 40 px context, a 24 px date and the lockup bottom-left. Nothing else; a title slide that argues is a bad title slide.
  • AgendaSix numbered items at 40 px with a 2 px rule between rows, so the audience knows how long the talk is.
  • Section dividerA full-bleed color field with a 72 px label and a 20 px number, used to break the deck into three acts.
  • Two column832 px of text beside 832 px of media with a 64 px gutter — the workhorse layout for anything with a screenshot.
  • DataA 1120 × 560 chart area with a 544 px takeaway column, so the number and its meaning sit on the same slide.
  • Quote and closingA 64/76 pull quote with attribution, and a closing frame with contact details and one call to action.

Canvas spec

Everything is measured from a 96 px margin, leaving 1728 px of content width — which is why two columns are 832 px each and the data slide splits 1120 + 64 + 544.

Open it

  1. File ▸ New from template — choose “Presentation slides”. The seven frames arrive on one page in running order.
  2. Save it — .figcraft on disk. A deck is a document you will revise, so keep it out of a scratch folder.
  3. Walk the flow before editing — the frames are already connected. Enter presentation view once to see the pacing you are about to change.
  4. Set the type before the content — the four sizes are text styles; using them keeps a long deck from drifting between slides.
  5. Check the fonts — a deck is the most visible place for a silent font fallback. ../craft-fonts must sit beside the source.

Make it yours

Decks fail on density, not decoration. These four settings control density.

Auto layout

Text that cannot overflow

The body column is a Fill-width vertical stack with a Fixed 96 px base and Hug height. Add a line and the block grows into empty space instead of over the footer.

Variables

Light and dark decks

A theme mode flips surfaces and text together, which matters in a dark room. Keep the data colors outside the mode so a chart does not change meaning.

Components

Slide furniture

Kicker, footer and page number are one component with variants per position. Change the footer once and all seven slides follow.

Prototype

Transitions as pacing

Triggers and transitions between frames set the rhythm. Use a dissolve for section changes and a short slide for lists; skip animation elsewhere.

What it does not give you

There is no PowerPoint export. Presentation view plays the prototype inside FigCraft, so handing the deck to someone else means exporting PDF or PNG — and the slides stop being clickable the moment they leave the app.

Test the export before you promise a single file: FigCraft writes PDF, PNG, JPG, WebP and SVG, but whether PDF batches a page of frames or writes one frame at a time is worth checking on your build. Speaker notes and a presenter console are not part of the starter either, so plan to carry the script separately. The project is an early alpha at about 49% parity by its own estimate — see known issues, and use keyboard shortcuts when you are building slides at speed.

Questions this page answers

Straight answers, with the limits stated. Every claim here is checkable against the sources linked above.

Can I export the deck to PowerPoint?

No. There is no PPTX writer. FigCraft exports PDF, PNG, JPG, WebP and SVG, and presentation view plays the prototype inside the app. If a client needs an editable PowerPoint, this starter gets you the layouts but not the file format.

How do I present from the starter?

The seven frames are connected with triggers and transitions, so you enter presentation view and click through them. That requires the app on the machine doing the presenting, which is the trade for not exporting a deck.

What type sizes does it use?

96 px for a title, 72 px for a section label, 40 px for body and agenda rows, 64 px for a pull quote, and 24 or 20 px for dates, attribution and page numbers, all on a 1920 × 1080 canvas.

Why is there also a 1280 × 720 frame?

Both sizes are 16:9, but the smaller frame is what older projectors and video calls actually show. Checking the compact frame catches body copy that is too small once the deck is scaled down to a laptop screen.
