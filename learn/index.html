How to use this section

FigCraft is an early alpha at roughly 49% parity with Figma, by the project's own estimate. That number is not the useful question. The useful questions are narrower: will my file open, what does the exporter actually write, can I drive this from a script, and what does it cost to leave Figma. There is one guide per question.

Every page is written against v0.9.0, released 2026-10-21. The project moves quickly, so where a behaviour is still in flux the page links the tracking issue instead of promising an outcome.

  • An exported SVG looks nothing like the canvasRead export SVG before blaming the renderer. Text kept as text and fonts the viewer does not have explain most of it.
  • The keys you learned on the demo do nothing in the appThey were never the app's keys. Keyboard shortcuts separates the two lists.

Where the demo studio fits

The canvas at /#demo is not the FigCraft app. It is this site's own studio, built to demonstrate a design workflow in the browser. Its shortcuts and its export formats are the studio's own, and every guide below marks the line where the two can be confused.

Use the demo for quick mockups, a colour or spacing sanity check, or to see how the interaction model feels. Use FigCraft for anything you intend to keep: only it writes .figcraft, runs the 400+ command engine, and opens .fig.

The reference tools are the exception — they measure rather than design, so they work either way: screen sizes, SVG minifier and contrast checker. Ready-made starting files are on templates.

Questions this page answers

Straight answers, with the limits stated. Every claim here is checkable against the sources linked above.

Is FigCraft ready for a production design team?

Not as a replacement for a hosted team tool. It is an early alpha at about 49% parity by the project's own estimate, with no accounts, teams or cloud. It is ready for solo interface work on local files, and for developers who want the same command engine in a script and in a UI.

Which version do these guides cover?

v0.9.0, released 2026-10-21, on macOS, Windows, Linux, FreeBSD and the WebAssembly build. Commands come from the project's own CLI, MCP and control-protocol documentation for that release.

Do these guides apply to the browser studio on this site?

Only where a page says so. The studio at /#demo is an independent canvas, not the FigCraft app: different renderer, different shortcuts, different export set. The pages that touch either one label it.

Where do I report a bug or check whether mine is known?

The tracker at github.com/storytold/figcraft/issues. This guide links the issues it can verify, and the curated shortlist is on known issues.

Is this an official FigCraft site?

No. It is an independent guide. The project's repository and release notes are the primary sources, and this site links them rather than paraphrasing them away.
