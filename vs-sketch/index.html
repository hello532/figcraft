FigCraft vs Sketch: the Mac original versus a Rust rewrite

Sketch defined the modern design tool and then stayed on one operating system. FigCraft is an attempt to rebuild the same idea in Rust, on every system, as open source.

Independent guide·Updated 2026-10-22·Covers FigCraft v0.9.0·6 min read
Download FigCraftOpen the studio

A Mac tool and a cross-platform one

Sketch sells a native macOS application, a web app and an iPhone and iPad viewer, with three subscription tiers and a one-time Mac licence. FigCraft sells nothing: it is a Rust binary for macOS, Windows, Linux and FreeBSD x86_64, plus a WebAssembly build, under MIT OR Apache-2.0, with no account and no telemetry.

The interesting comparison is not feature-for-feature. It is what each licence buys and what each one excludes. Sketch's cheapest option is a purchase; FigCraft's is a gift with maintenance attached.

The money, at five people

Five Sketch editors on Standard cost 5 × $12 = $60 a month, billed yearly. On Professional the same five are 5 × $24 = $120, and on Enterprise 5 × $44 = $220. The one-time alternative is 5 × $120 = $600 once, which includes a year of updates and no collaboration at all — for a team that has to share files, that licence is a dead end rather than a discount.

FigCraft's arithmetic is one line: $0, at any seat count, forever, because there is no licence server to ask. The cost arrives as labour. Fonts must sit in a sibling directory named ../craft-fonts, and issue #821 is still open on that workflow. macOS 27 on M1 has a launch crash (#781), Windows has a DX12 blur problem, and interface scaling breaks at 1440p (#540, #818).

One asymmetry is worth stating plainly: Sketch is macOS-only in our sources, so a studio with a Linux workstation or a Windows machine is not choosing between the two products at all. For those teams FigCraft is one of the few native options, which is the subject of the Linux page.

Who should pick which

  • One designer, one Mac, no collaboratorsSketch's $120 licence. It is a purchase rather than a subscription, and the missing collaboration is not a loss if there is nobody to collaborate with.
  • A studio on mixed operating systemsFigCraft, or a browser tool. Sketch has no Windows or Linux build in our sources, so it cannot be the shared tool for that team.
  • Automation and code handoffFigCraft. Export to SVG, PNG, JPG, WebP and PDF, and handoff to CSS, HTML, React, Leptos, SwiftUI and Compose, all scriptable through the CLI and MCP server.
  • A team that needs plugins and review flows todayNeither, honestly. Sketch's ecosystem was not verified here and FigCraft has no Figma plugin compatibility; a mature tool remains the safer pick.

What is genuinely unknown

We did not benchmark Sketch and will not pretend otherwise. Its file format, offline behaviour, handoff features and extension model are outside what its pricing page states, so those rows read Unverified. The same restraint applies in the other direction: FigCraft's roughly 49% parity is the project's own estimate against Figma, not a score in a contest with Sketch, and the project calls itself early alpha. Multiplayer is a preview and the public server is not end-to-end encrypted, so neither product on this page is a recommendation for a team that has to co-edit this week.

Questions this page answers

Straight answers, with the limits stated. Every claim here is checkable against the sources linked above.

Is FigCraft a drop-in replacement for Sketch?

No. FigCraft cannot be assumed to read Sketch files, and its parity with Figma is about 49% by the project own estimate, so parity with Sketch is not established at all. What transfers is the working model: artboards, components and local files. What does not transfer is the file itself or any plugin you relied on.

How much does Sketch cost for a small team?

Standard is $12 per editor per month billed yearly, so five editors are 5 × $12 = $60 a month. Professional is $24 and Enterprise $44 per editor, which makes five seats $120 and $220 respectively. The $120 one-time Mac licence is per designer, includes one year of updates, and excludes collaboration.

Can I use Sketch on Windows or Linux?

Not according to the sources we checked: Sketch is a native macOS app with a web app and an iPhone/iPad viewer. FigCraft ships native builds for macOS, Windows, Linux and FreeBSD x86_64, plus a WebAssembly build, which makes it the practical option for a mixed-OS team.

Which is better for handoff to developers?

FigCraft has the more explicit story: inspect, annotations, ready-for-dev and code output for CSS, HTML, React, Leptos, SwiftUI and Compose, free and scriptable through a CLI and MCP server with 400+ commands. Sketch handoff features were not verified for this page, so no comparison is offered.

Does FigCraft have a paid tier?

No. FigCraft is MIT OR Apache-2.0 with no account, no telemetry and no hosted service, so there is nothing to buy. That also means no support contract, no SLA and no vendor to escalate to when alpha bugs bite; the project tracker is the support channel.
